# MulenStream Kodi Repository

Veřejný instalační kanál pro Kodi. Obsahuje MulenStream a Subtrans.

Zdrojový repozitář MulenStreamu zůstává soukromý. Tento repozitář je záměrně
veřejný, protože Kodi z něj při instalaci a aktualizacích stahuje ZIP balíčky.

## Instalace do Kodi

1. V **Správce souborů** přidej zdroj:
   `https://marelhott.github.io/mulenstream-kodi-feed/repo/zips/repository.mulenstream/`
2. V **Doplňky → Instalovat ze ZIP souboru** zvol tento zdroj a
   `repository.mulenstream-1.0.0.zip`.
3. V **Instalovat z repozitáře → MulenStream Kodi Repository** nainstaluj
   **MulenStream** a ve skupině titulky také **Subtrans**.

Obsah `repo/` je generovaný distribuční obsah; neupravovat ručně.
